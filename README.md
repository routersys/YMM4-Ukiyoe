# 浮世絵 for YMM4

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](#)
[![.NET](https://img.shields.io/badge/.NET-10.0-purple.svg)](#)
[![Release](https://img.shields.io/github/v/release/routersys/YMM4-Ukiyoe.svg)](https://github.com/routersys/YMM4-Ukiyoe/releases)

---

YukkuriMovieMaker4（YMM4）上で動作する、素材を多色木版画の原画とみなして浮世絵調に刷り上げる映像エフェクトプラグインです。
輪郭主線はKang・Lee・Chuiの論文「Coherent Line Drawing」（NPAR 2007）のエッジ接線流と流れに沿った差分ガウスに基づきます。
地色はBi・Han・Yuの論文「An L1 Image Transform for Edge-Preserving Smoothing and Scene-Level Intrinsic Decomposition」（SIGGRAPH 2015）のL1局所平坦化を前向きの反復重み付き最小二乗として解いて均し、Winnemöllerらの「Real-Time Video Abstraction」（SIGGRAPH 2006）の軟量子化で限定パレットへ寄せます。
履歴フレーム、参照画像、学習済みモデルを使わず、入力された一枚の映像だけを処理します。
和紙の繊維とばれん目と版ずれの形はシードから決定論的に決まり、同じ設定では常に同じ絵になります。
強さ、線の太さ、線の流れ、線の量、線の濃さ、平坦化、版ずれ、ばれん目、和紙の9項目はアニメーションに対応しています。

## 概要

本プラグインはYMM4の映像エフェクトとして動作し、エフェクトの種類一覧では「浮世絵」として表示されます。カテゴリは加工と装飾です。

入力された現在のフレームの色とアルファ値から素材の絵柄を求め、多色木版画の工程になぞらえて3つの層を刷り重ねます。主線の層は、エッジ接線流の非線形ベクトル平滑化で絵柄の流れを求め、流れに直交する方向の差分ガウスを流線に沿って集計して、つながりの良い輪郭線を取り出します。色面の層は、L1ノルムの局所平坦化を反復重み付き最小二乗として解き、細部を消しながら際を保った均質な色面を作り、輝度の軟量子化で限定パレットの階調へ寄せます。意匠の層は、階調ごとの刷り位置のずれ、ばれんの擦り跡、和紙の繊維のかすれを決定論的なハッシュ模様として重ねます。

計算はComputeSharpの計算シェーダーがDirect3D 12で実行します。YMM4のDirect3D 11側とComputeSharpのDirect3D 12側は、共有テクスチャと共有フェンスで接続します。通常のフレーム処理では、CPUへの画素の読み戻しを行わず、8個の整数の読み戻しだけで素材の変化を判定します。素材が存在する最小の矩形の範囲だけを描画し、絵柄と構造のパラメータが変わらないフレームでは輪郭と平坦化の計算を再利用します。

このエフェクトはAviUtl向けのEXO出力には対応していません。

## インストール方法

1. [Releases](https://github.com/routersys/YMM4-Ukiyoe/releases/latest)ページから最新のプラグインファイル（`.ymme`）をダウンロードしてください。
2. YMM4が起動していないことを確認し、ダウンロードしたファイルを実行してインストールします。
3. YMM4を起動し、タイムライン上のアイテムに映像エフェクトを追加します。
4. 映像エフェクトの種類として「浮世絵」を選択してください。

## 主な機能

### 1. エッジ接線流と流れに沿った差分ガウスによる主線

現在のフレームの輝度からソーベル勾配を求め、勾配に直交する接線場を核関数に基づく非線形ベクトル平滑化で整えます。有意なエッジの方向を保ちながら弱い方向を周囲の支配的な流れへ従わせ、勾配のほとんどない領域は近傍の有意な接線の構造テンソルの主固有ベクトルで充填します。この充填により、素材の内部に緩やかな陰影があってもシルエットの輪郭線が途切れません。

主線は、流れに直交する方向の1次元差分ガウスを流線に沿って集計する、流れに沿った差分ガウスで取り出します。線の太さは差分ガウスの中心幅、線の流れは流線方向の集計の長さ、線の量は二値化のしきい値を決めます。前回の主線を重ねてから再度適用する反復で、線のつながりをさらに強めます。

### 2. L1平坦化による色面

地色は、隣接する画素の色の差のL1ノルムと元画像への近さの和を最小化する局所平坦化で均します。似た色の隣接対には大きな重みが付くため差が強く縮み、際をまたぐ対には小さな重みしか付かないため際が保たれます。L1ノルムの性質により、似た色はさらに近づき、異なる色は離れたまま残る区分平坦な色面が得られます。

最小化は反復重み付き最小二乗のヤコビ反復として前向きに解きます。分解や推定を伴わないため、入力によらず常に均質な色面が出ます。平坦化のパラメータは元画像への近さの重みを決め、高いほど細部が消えます。

### 3. 限定パレットの階調化

平坦化した色面の暗さを、色数で指定した段数の階調へ軟量子化します。階調の中心が平坦になり、階調の境界だけで滑らかに切り替わるため、木版画の色版のような均質な色面になります。彩度は量子化せず、平坦化とスケールで整えます。

### 4. 版ずれ

多色木版画の見当ずれを再現します。階調の層ごとにシードから決めた方向へ刷り位置をずらし、各画素で自身より暗い層のずらした標本を調べて最も暗い層の色を採用します。階調の境界に色縁が出て、素材の外側にもわずかにはみ出します。主線の版はずらしません。

### 5. ばれん目と和紙

ばれん目は、ばれんの擦り跡の同心円模様です。セルごとに中心をずらした円環模様を低周波の斑と掛け合わせ、中間調の色面をわずかに明るくします。

和紙は、3オクターブの値ノイズによる繊維場です。色面と主線を繊維で削り、かすれを作ります。

シードは、和紙の繊維とばれん目と版ずれの形を決める固定値です。シードと画素位置から決定論的に生成するため、同じシードと同じパラメータでは常に同じ絵になります。

### 6. 品質の選択

品質は、処理格子の解像度と各段階の反復回数をまとめて切り替えます。

| 品質 | 格子解像度 | 接線流反復 | 主線反復 | 平坦化反復 |
|---|---:|---:|---:|---:|
| 標準 | 1024 | 2回 | 2回 | 24回 |
| 高品質 | 1440 | 3回 | 2回 | 40回 |
| 最高品質 | 2048 | 3回 | 3回 | 64回 |

格子解像度は計算領域の長辺のセル数です。短辺のセル数は計算領域の縦横比に合わせて決めます。

## 制限事項

- AviUtl向けのEXO出力には対応していません。
- Direct3D 12デバイスを取得できない場合や、YMM4が使うDirect3D 11デバイスとの共有テクスチャおよび共有フェンスを作成できない場合は、エフェクトを適用せず入力映像を表示します。
- 現在のフレームの色とアルファ値だけを使用します。履歴フレーム、外部画像、学習済みモデルは使用しません。
- 計算領域は素材の範囲に主線の到達範囲と版ずれと描画の余白を加えた大きさで、長辺は8192画素が上限です。素材が大きく余白を確保できない場合は、エフェクトを適用せず入力映像を表示します。
- 処理量とGPUメモリ使用量は、計算領域の大きさと品質に応じて増えます。

## 注意事項

- 処理負荷: 最高品質は処理格子の解像度と反復回数が最も多いため、高品質と標準より処理負荷が高くなります。描画は素材が存在する最小の矩形の範囲だけを計算します。
- キャッシュ: 素材の色と形および構造を決めるパラメータが変わらないフレームでは、輪郭と平坦化の計算を再利用します。色数、版ずれ、ばれん目、和紙、線の濃さ、主線色、シードだけを変えたフレームでは、構造を再計算しません。
- 強さ0%: 強さが0%のときは入力を変更しません。
- シードと再現性: 和紙の繊維とばれん目と版ずれの形は、シードと画素位置から決定論的に算出します。時間値は生成に使用しません。
- 透明部分: 主線と版ずれは素材の外側にもわずかに描画されるため、出力範囲は素材より広がります。出力は元映像と強さの割合で合成します。
- 更新通知: エフェクトを最初に生成したときに、YMM4の実行中に一度だけ新しい正式版を確認します。更新情報を取得できない場合は通知せず、そのまま動作します。プレリリースは通知の対象に含めません。
- 本プラグインを使用する前に、YMM4のプロジェクトファイルのバックアップを作成することを推奨します。
